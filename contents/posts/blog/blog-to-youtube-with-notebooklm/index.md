안녕하세요, **자바파커**입니다.

블로그에 글을 열심히 써도, 읽는 사람이 한정되어 있다는 걸 느낄 때가 있습니다.

> "이 글을 영상으로도 만들 수 있으면 좋겠는데, 촬영도 편집도 할 줄 모르는데..."

결론부터 말씀드리면 — **Google NotebookLM을 쓰면 블로그 글 하나로 AI 동영상을 만들 수 있습니다.** 촬영 장비도, 영상 편집 기술도 필요 없습니다. 글만 있으면 됩니다.

이 글에서는 제가 실제로 블로그 포스팅을 NotebookLM 동영상으로 변환하고, 유튜브에 업로드한 전체 과정을 공유합니다.

---

## 전체 워크플로우 — 3단계

전체 흐름을 먼저 보면 이렇습니다.

```
블로그 글 작성 → NotebookLM에 업로드 → AI 동영상 생성 → 유튜브 업로드
```

| 단계 | 도구 | 소요 시간 |
|------|------|----------|
| 1. 글 작성 | 티스토리 / 마크다운 | 이미 완료 |
| 2. 동영상 생성 | NotebookLM | 5~30분 (자동) |
| 3. 유튜브 업로드 | YouTube Studio | 5~10분 |

핵심은 **이미 쓴 글을 재활용**한다는 것입니다. 새로 콘텐츠를 만드는 게 아닙니다.

---

## 1단계: 블로그 글 준비

### 어떤 글이 동영상으로 적합한가?

모든 글이 영상으로 잘 변환되는 건 아닙니다.

| 적합한 글 | 부적합한 글 |
|-----------|-----------|
| 개념 설명, 비교 분석 | 코드 위주의 튜토리얼 |
| 단계별 가이드 | 짧은 팁/메모 |
| 도구 소개, 후기 | 코드 스니펫 모음 |
| FAQ, 체크리스트 | 표만 있는 정리글 |

예를 들어, "AI로 웹서비스 만드는 법" 같은 글은 동영상으로 만들면 시각적으로 설명이 풍부해져서 효과적입니다. 반면 코드 줄 하나하나를 설명하는 튜토리얼은 텍스트가 더 낫습니다.

### 글을 준비하는 방법

NotebookLM에 소스를 넣는 방법은 여러 가지입니다.

- **웹 URL 붙여넣기** — 티스토리 포스팅 URL을 그대로 입력
- **텍스트 복사/붙여넣기** — 마크다운이나 텍스트를 직접 붙여넣기
- **Google Docs** — 구글 문서로 옮긴 후 연결
- **PDF 업로드** — 글을 PDF로 변환 후 업로드

가장 간단한 건 **블로그 URL을 그대로 넣는 것**입니다.

## 2단계: NotebookLM으로 AI 동영상 생성

### NotebookLM 접속 및 노트북 생성

1. [NotebookLM](https://notebooklm.google.com) 접속 (구글 계정으로 로그인)
2. **새 노트북 만들기** 클릭
3. **소스 추가** > 웹사이트 URL 또는 텍스트 붙여넣기

[이미지: NotebookLM 소스 추가 화면]

### Video Overview 생성

소스를 추가하면 오른쪽에 **Studio 패널**이 나타납니다.

1. Studio 패널에서 **Video Overview** 선택
2. **동영상 형식** 선택
3. 필요하면 **커스텀 프롬프트**로 초점을 지정
4. **생성** 클릭

[이미지: Video Overview 생성 버튼 클릭 화면]

### 동영상 형식 — 3가지 비교

| 형식 | 특징 | 가격 | 추천 용도 |
|------|------|------|----------|
| **Brief** | 1~2분, 핵심 요약 | 무료 | SNS 공유, 짧은 소개 |
| **Explainer** | 3~5분, 개념 설명 | 무료 | 유튜브 업로드, 학습 콘텐츠 |
| **Cinematic** | 5분 이상, 풍부한 애니메이션 | Ultra ($250/월) | 프로 수준 프레젠테이션 |

**무료 계정**으로는 Brief와 Explainer를 사용할 수 있습니다. 블로그 글을 유튜브 영상으로 만드는 용도라면 **Explainer**가 가장 적합합니다.

### 커스텀 프롬프트 활용

그냥 생성해도 되지만, 프롬프트를 주면 결과물이 더 좋아집니다.

```
"이 글의 핵심 내용을 개발자 독자를 위해 설명해줘.
Claude Code와 Supabase의 조합이 왜 효과적인지에 초점을 맞춰줘."
```

프롬프트로 제어할 수 있는 것들:

- **초점** — 어떤 부분을 중점적으로 다룰지
- **톤** — 전문적 / 캐주얼 / 교육적
- **대상** — 초보자용 / 경험자용

### 생성 시간

생성 버튼을 누르면 5~30분 정도 걸립니다. 페이지를 닫아도 백그라운드에서 생성이 계속됩니다. 완료되면 노트북에서 확인할 수 있습니다.

## 3단계: 유튜브에 업로드

### 동영상 다운로드

NotebookLM에서 생성된 동영상을 **다운로드** 합니다. MP4 파일로 저장됩니다.

### YouTube Studio에서 업로드

1. [YouTube Studio](https://studio.youtube.com) 접속
2. 오른쪽 상단 **만들기** > **동영상 업로드** 클릭
3. 다운로드한 MP4 파일 선택

### 메타데이터 설정 — SEO가 여기서도 중요

블로그 SEO와 마찬가지로, 유튜브도 검색 최적화가 중요합니다.

| 항목 | 팁 |
|------|-----|
| **제목** | 블로그 제목을 그대로 쓰되, "영상 ver." 느낌 추가 |
| **설명** | 블로그 원문 링크 + 핵심 내용 요약 3~5줄 |
| **태그** | 블로그 태그와 동일 + "NotebookLM", "AI 동영상" 추가 |
| **썸네일** | 블로그 대표이미지를 재활용하거나 약간 변형 |
| **카테고리** | 과학/기술 또는 교육 |

## 콘텐츠 재활용 전략 — 글 하나로 3가지 만들기

이 워크플로우의 진짜 가치는 **하나의 콘텐츠를 여러 형태로 재활용**하는 것입니다.

```
블로그 글 (원본)
  ├── NotebookLM Explainer → 유튜브 영상
  ├── NotebookLM Brief → SNS 숏폼 (인스타, 쇼츠)
  └── NotebookLM Audio Overview → 팟캐스트
```

| 콘텐츠 형태 | 플랫폼 | NotebookLM 형식 |
|------------|--------|----------------|
| 블로그 글 | 티스토리 | 원본 |
| 유튜브 영상 | YouTube | Explainer / Cinematic |
| 숏폼 영상 | YouTube Shorts, 인스타 | Brief |
| 팟캐스트/오디오 | Spotify, 팟빵 | Audio Overview |

글 하나 쓰면 4가지 채널에 콘텐츠를 배포할 수 있습니다. 1인 크리에이터에게는 이만한 효율이 없습니다.

## 주의할 점

### AI 생성 콘텐츠 표시

유튜브는 AI로 만든 영상에 대해 **AI 생성 콘텐츠임을 표시**하도록 권장하고 있습니다. YouTube Studio 업로드 시 "변경되거나 합성된 콘텐츠" 옵션에서 해당 사항을 체크하세요.

### 무료 계정 제한

무료 NotebookLM 계정은 생성 횟수에 제한이 있습니다. 한 노트북당 생성 가능한 동영상 수가 정해져 있으므로, 프롬프트를 잘 작성해서 한 번에 만족스러운 결과를 얻는 게 중요합니다.

### 한국어 지원

Video Overview는 한국어를 포함한 여러 언어를 지원합니다. 다만 Cinematic 형식은 현재 영어만 지원됩니다. 무료로 사용하는 Brief/Explainer는 한국어로 생성 가능합니다.

## 자주 묻는 질문 (FAQ)

### NotebookLM Video Overview는 무료인가요?

Brief와 Explainer 형식은 무료로 사용할 수 있습니다. 구글 계정만 있으면 됩니다. Cinematic 형식만 Ultra 구독($250/월)이 필요하지만, 블로그 글을 유튜브 영상으로 만드는 용도라면 Explainer로 충분합니다.

### 블로그 글 URL을 넣으면 자동으로 전체 내용을 읽나요?

네, NotebookLM이 웹페이지의 텍스트 콘텐츠를 자동으로 추출합니다. 다만 이미지나 코드 블록의 세부 내용은 반영되지 않을 수 있으므로, 중요한 내용이 텍스트로 잘 작성되어 있는지 확인하세요.

### 생성된 동영상의 저작권은 누구에게 있나요?

NotebookLM으로 생성한 동영상의 저작권은 생성자에게 있습니다. 상업적 사용도 가능합니다. 다만 원본 블로그 글의 내용이 타인의 저작물을 포함하고 있다면 별도로 확인이 필요합니다.

## 마무리

정리하면, 블로그 글을 유튜브 영상으로 만드는 과정은 이렇습니다.

1. **블로그에 글을 쓴다** — 이미 하고 있는 일
2. **NotebookLM에 URL을 넣고 Video Overview를 생성한다** — 5분 클릭
3. **다운로드해서 유튜브에 업로드한다** — 메타데이터만 잘 채우면 끝

핵심은 **새로운 콘텐츠를 만드는 게 아니라, 이미 쓴 글을 다른 형태로 변환하는 것**입니다. 글 쓰는 시간은 이미 투자했으니, 추가 10분만 투자하면 유튜브 채널까지 운영할 수 있습니다.

저도 이 블로그의 포스팅을 하나씩 영상으로 변환해볼 예정입니다. 진행 과정도 공유하겠습니다.
