안녕하세요, **자바파커**입니다.

> "Claude Code? Codex? 그거 개발자만 쓰는 거 아닌가요?"

솔직히 저도 처음엔 그렇게 생각했습니다. 터미널에 명령어를 치는 도구라니, 당연히 개발자 전용이겠거니 했죠. 그런데 직접 써보니 **코딩을 전혀 모르는 사람이야말로 이 도구들의 진짜 수혜자**라는 걸 깨달았습니다.

결론부터 말씀드리면 — **비개발자도 충분히 쓸 수 있고, 오히려 반복 업무 자동화에서 엄청난 효과를 볼 수 있습니다.** 오늘은 Claude Code와 OpenAI Codex CLI, 이 두 도구를 비개발자 관점에서 설치부터 실전 활용까지 정리해보겠습니다.

---

## 먼저, 이 도구들이 뭔가요?

쉽게 비유하자면 이렇습니다.

| | ChatGPT / Claude 웹 | Claude Code / Codex CLI |
|---|---|---|
| **비유** | 카카오톡으로 비서에게 부탁 | 비서가 직접 내 컴퓨터 앞에 앉아서 작업 |
| **할 수 있는 것** | 텍스트 답변, 조언 | 파일 읽기/수정, 폴더 정리, 코드 실행, 자동화 |
| **작업 범위** | 대화창 안에서만 | 내 컴퓨터의 실제 파일과 폴더 |

**Claude Code**는 Anthropic이 만든 AI 에이전트 도구이고, **Codex CLI**는 OpenAI가 만든 도구입니다. 둘 다 터미널(명령 프롬프트)에서 자연어로 지시하면 **내 컴퓨터의 파일을 직접 읽고, 수정하고, 생성**해줍니다.

핵심은 이겁니다 — **코딩을 해달라고 시키는 게 아니라, 일을 해달라고 시키는 겁니다.**

## 비개발자가 할 수 있는 일 10가지

코딩과 전혀 관련 없는 실전 활용 사례입니다.

### 업무 자동화

1. **경비 보고서 정리** — 여러 신용카드 명세서(CSV)를 하나로 합치고 카테고리별로 분류
2. **이메일/뉴스레터 초안** — 프로젝트 폴더의 변경사항을 읽고 주간 보고 메일 초안 작성
3. **파일 정리** — 수백 개 파일을 날짜별, 유형별로 자동 분류하고 이름 변경

### 콘텐츠 & 마케팅

4. **블로그 포스팅 초안** — 주제를 주면 리서치 + 마크다운 초안까지 한 번에
5. **SNS 콘텐츠 배치 생성** — 하나의 긴 글에서 트위터/인스타/링크드인용 요약본 자동 생성
6. **SEO 분석** — 경쟁사 페이지를 분석하고 키워드 리포트 생성

### 데이터 분석

7. **스프레드시트 가공** — CSV/엑셀 파일에서 특정 조건의 데이터만 추출, 피벗
8. **미사용 구독 감지** — 은행 거래 내역에서 반복 결제를 찾아 리스트업
9. **설문 결과 분석** — 설문 응답 데이터를 요약하고 인사이트 도출

### 일상

10. **여행 계획** — 날짜, 예산, 취향을 알려주면 일정표 마크다운 파일로 생성

## Claude Code 설치 가이드 (비개발자용)

### 사전 준비

Claude Code를 쓰려면 두 가지가 필요합니다:

1. **Anthropic 유료 구독** — 최소 Pro 플랜($20/월)
2. **Node.js** — Claude Code 설치에 필요한 기본 도구

### 1단계: Node.js 설치

[nodejs.org](https://nodejs.org) 접속 → **LTS 버전** 다운로드 → 설치 (모든 옵션 기본값 OK)

설치 확인:

```bash
node --version
# v22.x.x 같은 버전이 나오면 성공
```

### 2단계: Claude Code 설치

```bash
npm install -g @anthropic-ai/claude-code
```

> 💡 **Windows 사용자**: PowerShell 또는 Git Bash에서 실행하세요.

### 3단계: 실행 및 인증

```bash
# 작업할 폴더로 이동
cd ~/Documents/내작업폴더

# Claude Code 실행
claude
```

처음 실행하면 브라우저가 열리면서 Anthropic 계정 인증을 요청합니다. 로그인하면 바로 사용 가능합니다.

### 4단계: 첫 번째 대화

```
> 이 폴더에 있는 파일 목록을 정리해서 summary.md로 만들어줘
```

이게 끝입니다. 코드를 작성한 게 아니라 **한국어로 부탁한 것**뿐입니다.

## Codex CLI 설치 가이드 (비개발자용)

### 사전 준비

1. **ChatGPT Plus 이상 구독** — Plus($20/월) 또는 Pro($200/월)
2. **Node.js 18 이상** (위와 동일)

### 1단계: 설치

```bash
npm install -g @openai/codex
```

### 2단계: 인증

```bash
codex
```

실행하면 "Sign in with ChatGPT" 옵션이 나옵니다. 브라우저에서 로그인하면 완료.

### 3단계: 첫 번째 대화

```
> 이 폴더의 CSV 파일들을 읽고 날짜별로 정렬해서 하나로 합쳐줘
```

> ⚠️ **Windows 사용자 주의**: Codex CLI의 Windows 지원은 아직 실험적입니다. WSL2(Windows Subsystem for Linux) 환경을 권장합니다.

## Claude Code vs Codex CLI — 비개발자 관점 비교

| 항목 | Claude Code | Codex CLI |
|------|------------|-----------|
| **시작 난이도** | ⭐⭐ 쉬움 | ⭐⭐ 쉬움 (Windows는 ⭐⭐⭐) |
| **한국어 지원** | 매우 자연스러움 | 자연스러움 |
| **안전성** | 변경 전 확인 요청 (감독형) | full-auto 모드 있음 (비감독형 가능) |
| **Windows 지원** | 네이티브 지원 | 실험적 (WSL 권장) |
| **최소 비용** | $20/월 (Pro) | $20/월 (Plus) |
| **사용량 제한** | 5시간 제한 (Pro) | 모델별 상이 |
| **데스크톱 앱** | 있음 (Mac/Windows) | 없음 |
| **웹 버전** | 있음 (claude.ai/code) | 없음 |
| **VS Code 연동** | 있음 | 있음 |

### 비개발자에게 추천하는 선택은?

**Claude Code를 먼저 추천합니다.** 이유는:

1. **감독형 방식** — 파일을 수정하기 전에 항상 확인을 요청합니다. 실수로 중요한 파일을 날릴 걱정이 적습니다.
2. **Windows 네이티브 지원** — WSL 설치 없이 바로 사용 가능합니다.
3. **데스크톱 앱/웹 버전** — 터미널이 어색하면 데스크톱 앱이나 웹에서 시작할 수 있습니다.
4. **VS Code 확장** — VS Code에서 직접 사용하면 터미널을 따로 열 필요도 없습니다.

Codex CLI는 **이미 ChatGPT Plus를 구독 중**이거나, **터미널 작업에 어느 정도 익숙한 분**에게 적합합니다.

## 비개발자를 위한 실전 팁 5가지

### 1. CLAUDE.md (또는 AGENTS.md) 파일을 활용하세요

프로젝트 폴더에 `CLAUDE.md` 파일을 만들어두면, Claude Code가 매번 대화를 시작할 때 이 파일을 읽습니다. 일종의 **업무 매뉴얼**입니다.

```markdown
# 이 폴더에 대한 설명

- 이 폴더에는 매월 경비 보고 CSV 파일이 저장됩니다
- 파일 형식: YYYY-MM-expenses.csv
- 카테고리: 교통, 식비, 숙박, 기타
- 월말에 summary.xlsx로 합산 보고서를 만들어야 합니다
```

이렇게 해두면 매번 같은 설명을 반복하지 않아도 됩니다.

### 2. 작업 전 백업 습관을 들이세요

AI가 파일을 직접 수정할 수 있으므로, 중요한 파일은 **작업 전에 복사본**을 만들어두세요.

```
> 작업 시작하기 전에 이 폴더를 backup 폴더로 복사해줘
```

이것도 자연어로 시키면 됩니다.

### 3. 프롬프트는 구체적일수록 좋습니다

```
❌ "이 파일 정리해줘"
✅ "expenses.csv에서 2024년 3월 데이터만 추출해서 march-report.csv로 저장해줘. 금액 기준 내림차순으로 정렬하고."
```

### 4. 모르겠으면 물어보세요

```
> 이 폴더에 어떤 파일들이 있는지 먼저 알려줘
> 이 CSV 파일의 구조(컬럼)를 설명해줘
> 이걸 엑셀로 변환할 수 있어?
```

Claude Code와 Codex 모두 **대화형**이므로, 바로 작업을 시키지 않고 먼저 상황 파악을 요청해도 됩니다.

### 5. 비용 관리에 신경 쓰세요

| 사용 패턴 | 권장 플랜 | 월 비용 |
|-----------|-----------|---------|
| 가끔 (주 1~2회) | Pro / Plus | ~$20 |
| 매일 가볍게 | Pro / Plus | ~$20 |
| 매일 집중적으로 | Max | ~$100 |
| 헤비 유저 | Max / Pro (Codex) | $100~200 |

특히 Claude Code Pro 플랜은 **5시간 사용 제한**이 있으므로, 가벼운 작업 위주라면 충분하지만 하루 종일 붙잡고 있으면 금방 한도에 도달합니다.

## 비개발자가 자주 하는 질문 (FAQ)

### Q. 터미널(명령 프롬프트)을 한 번도 써본 적이 없는데 괜찮을까요?

괜찮습니다. 필요한 명령어는 딱 세 개입니다:
- `cd 폴더경로` — 폴더 이동
- `claude` 또는 `codex` — 도구 실행
- `exit` — 종료

나머지는 전부 자연어로 대화하면 됩니다. VS Code 확장이나 데스크톱 앱을 쓰면 터미널 자체를 건드릴 일이 더 줄어듭니다.

### Q. AI가 중요한 파일을 잘못 수정하면 어떡하죠?

Claude Code는 **기본적으로 파일을 수정하기 전에 확인을 요청**합니다. "이 파일을 이렇게 바꿔도 될까요?"라고 물어보고, 사용자가 승인해야 실행됩니다. Codex CLI도 기본 모드에서는 동일합니다. 다만 Codex의 `full-auto` 모드는 확인 없이 바로 실행하므로, 비개발자는 기본 모드를 유지하는 것을 권장합니다.

### Q. ChatGPT나 Claude 웹에서 하던 작업과 뭐가 다른가요?

가장 큰 차이는 **내 컴퓨터의 파일에 직접 접근**할 수 있다는 점입니다. 채팅 인터페이스에서는 "이런 코드를 만들어줘"라고 하면 텍스트로 결과를 보여주기만 합니다. Claude Code나 Codex는 실제로 파일을 만들고, 기존 파일을 수정하고, 프로그램을 실행까지 해줍니다.

## 마무리

"코딩을 모르면 AI 에이전트 도구를 못 쓴다"는 건 이제 옛말입니다. Claude Code와 Codex CLI는 **자연어로 지시하면 내 컴퓨터에서 직접 작업을 수행하는 도구**이고, 그 지시에 코드가 필요하지 않습니다.

시작이 어렵게 느껴지시면, 딱 하나만 해보세요:

```bash
npm install -g @anthropic-ai/claude-code
claude
> 이 폴더에 있는 파일들을 정리해서 목록 만들어줘
```

이 한 줄이 시작입니다. 한 번 경험하고 나면 "이것도 시킬 수 있지 않을까?" 하는 생각이 자연스럽게 따라올 겁니다.
